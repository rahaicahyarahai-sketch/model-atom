{/* Pengertian */}

Pengertian

Atom adalah partikel kecil yang merupakan penyusun dasar materi. Model atom adalah representasi konseptual tentang struktur atom dan perilaku elektronnya. Ada beberapa model penting:

  • Model Thomson (plum-pudding): atom bermuatan positif dengan elektron tersebar seperti kismis dalam puding.
  • Model Rutherford: atom memiliki inti kecil bermuatan positif (proton) dan elektron mengelilingi inti; ditemukannya inti melalui eksperimen hamburan partikel alpha.
  • Model Bohr: elektron mengorbit inti pada lintasan diskret (kulit) dengan energi tertentu — cocok untuk menjelaskan spektrum hidrogen.
{/* Rumus */}

Rumus Penting (Model Bohr & Spektrum)

Beberapa rumus yang sering muncul:

  1. Energi pada tingkat n (untuk atom hydrogen-like):
    E_n = - (m e^4) / (8 ε₀^2 h^2) · (Z^2 / n^2) = -13,6 eV · (Z^2 / n^2)

    (untuk atom hidrogen Z=1 → E_n = -13,6 eV / n^2)

  2. Perubahan energi saat transisi (emis/absorpsi foton):
    ΔE = E_f - E_i = h ν = h c / λ

    Gunakan tanda negatif/positif sesuai energi awal dan akhir.

  3. Rumus Rydberg (untuk panjang gelombang spektrum hidrogen):
    1/λ = R (1/n_f^2 - 1/n_i^2), R ≈ 1,097×10^7 m⁻¹

Catatan: rumus di atas berlaku tepat untuk atom hidrogen. Untuk atom lain digunakan Z (nomor atom) pada formula energi Bohr (hanya berlaku untuk sistem hydrogen-like).

{/* Contoh soal */}

Contoh Soal dan Pembahasan

Soal 1

Elektron pada atom hidrogen berada pada tingkat energi n = 3 lalu turun ke n = 2. Hitung panjang gelombang foton yang dipancarkan. (Gunakan R = 1,097×107 m-1.)

Pembahasan

Gunakan rumus Rydberg:

1/λ = R(1/n_f^2 - 1/n_i^2) = R(1/2^2 - 1/3^2) = R(1/4 - 1/9) = R(5/36).

Jadi 1/λ = 1,097×107 × 5/36 = 1,5236×106 m-1 → λ ≈ 6,56×10-7 m = 656 nm.

Soal 2

Energi relatif tingkat n = 1 dan n = 2 pada atom hidrogen. Berapa energi masing-masing tingkat (dalam eV)?

Pembahasan

E_n = -13,6 eV / n^2 → E_1 = -13,6 eV, E_2 = -13,6 / 4 = -3,4 eV.

Soal 3 (Aplikasi Z)

Hitung energi dasar (n=1) pada ion He+ (Z = 2).

Pembahasan

E_1 = -13,6 eV × Z^2 = -13,6 × 4 = -54,4 eV.
